# Персональный Ассистент - Анализ Проекта

## Цель
Создать Telegram-бота (`@YourPersonalAssistantBot`), который принимает голосовые сообщения, переводит их в текст с помощью **Groq (Whisper)**, анализирует намерение через **DeepSeek** и выполняет действия (в первую очередь генерацию **.ics файлов календаря**).

## Технологический стек
*   **Язык**: Python 3.11+
*   **Фреймворк**: `aiogram` (Telegram Bot API)
*   **Транскрибация**: Groq API (`whisper-large-v3-turbo`)
*   **Интеллект**: DeepSeek API (`deepseek-chat`)
*   **Календарь**: Генерация `.ics` файлов (библиотека `ics`)
*   **Окружение**: `.env` для ключей

## Архитектура
1.  **Интерфейс Бот**:
    *   Получает `Voice` сообщения.
    *   Скачивает файл во временное хранилище.
2.  **Обработка Аудио (Уши)**:
    *   Отправляет файл в Groq API.
    *   Получает текстовую расшифровку.
3.  **Парсинг Намерений (Мозг)**:
    *   Отправляет текст в DeepSeek с системным промптом.
    *   Пример JSON: `{"intent": "create_event", "summary": "Встреча", "start_time": "...", "end_time": "..."}`
4.  **Выполнение Действий (Руки)**:
    *   **Действие: Создать событие**: Генерирует `.ics` файл с событием.
    *   **Ответ**: Бот присылает файл пользователю.

## Примечание по Сети / VPN
Пользователь использует VPN для доступа к Groq. Бот работает на локальной машине с активным VPN.
