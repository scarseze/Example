# BCS Manager (InvestManager)

**Android-приложение для управления инвестиционным портфелем.**

![Android](https://img.shields.io/badge/Platform-Android-green) ![Kotlin](https://img.shields.io/badge/Language-Kotlin-purple) ![Architecture](https://img.shields.io/badge/Arch-MVVM-blue)

## Обзор

Современное Android-приложение для отслеживания активов, просмотра умной ленты новостей и мониторинга рыночных метрик.

**Новое в v2.0 (Оптимизация):**
*   **Async Core**: Полностью переписан `NewsRepository` с использованием **Kotlin Coroutines**. Приложение больше не зависает при сетевых запросах.
*   **Стабильность**: Исправлены критические ошибки авторизации (401) и падения из-за некорректного JSON от нейросетей.
*   **Безопасность**: Реализовано безопасное логирование (скрытие API-ключей в логах).

## Стек Технологий

*   **Язык**: Kotlin
*   **Архитектура**: MVVM (Model-View-ViewModel) + Clean Architecture
*   **Сеть**: Retrofit + OkHttp
*   **Асинхронность**: Coroutines & Flow
*   **Данные**: Room Database (Локальный кэш)

## Основные Функции

1.  **Трекинг Портфеля**: Оценка стоимости активов в реальном времени.
2.  **Умные Новости**: Фильтрация новостного потока по вашим тикерам с использованием Regex.
3.  **AI Интеграция**: Отображение сгенерированных нейросетью саммари и сентимента для новостей.
